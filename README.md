# we_want_keyboard

## Overview

This repository contains a Godot game project and an Arduino sketch for a keyboard controller.

- `src/` – Godot source files (scripts, scenes, assets).
- `arduino/` – Arduino sketch and build artifacts.
- `scripts/` – Helper scripts for building, cleaning, and linting.
- `docs/` – Project documentation.
- `build/` – Generated build artifacts (Game exports, compiled Arduino hex).

Refer to the files in the `docs/` folder for detailed setup and usage instructions.
